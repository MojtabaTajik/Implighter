Every block gets one of three verdicts, which is why some text stays plain rather than highlighted or hidden:

Core
What you came for. Always highlighted.
Supporting
The sentence that sets up a core point, a caveat on a core claim, the paragraph that connects two. Kept plain in the first two modes — hiding it strands highlights with no premise behind them. Only highlights removes it anyway, which reads as fragments but skims fastest.
Headings are the exception and survive in every mode, including the page title. Structure is not substance, and without it the result has nothing saying where you are.
Noise
Marketing, bios, newsletter pitches, comment threads. Dimmed or hidden.
